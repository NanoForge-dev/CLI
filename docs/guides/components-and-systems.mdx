---
title: Add components and systems
description: Create your own ECS components and systems, or install shared ones
---

A NanoForge game is made of ECS **components** (data on an entity) and **systems** (functions
that run every tick on the entities that have some components). You can write your own or install
them from the registry.

## Create your own

<Steps>
  <Step title="Create a component">

    In a client app (or a project without a server), run:

    ```bash
    nf create component --name health
    ```

    It writes `src/components/health.component.ts`, with a `HealthComponent` class. In a
    workspace, point `-d` at the app: `nf create component --name health -d apps/server` creates a
    server component.

    Open the file and change the import to `@nanoforge-dev/ecs`: the template imports
    `@nanoforge-dev/ecs-client`, which your project doesn't install. Then replace the example
    parameters with your data.

  </Step>

  <Step title="Create a system">

    ```bash
    nf create system --name regen
    ```

    It writes `src/systems/regen.system.ts`, with a `regenSystem` function. Fix the import the
    same way, and replace `ExampleComponent` with your component:

    ```ts src/systems/regen.system.ts
    import type { Context } from "@nanoforge-dev/common";
    import type { EditorSystemManifest, Registry } from "@nanoforge-dev/ecs";

    import { HealthComponent } from "../components/health.component";

    export const regenSystem = (registry: Registry, _ctx: Context) => {
      registry.getZipper([HealthComponent]).forEach((entity) => {
        entity.HealthComponent.addOne();
      });
    };
    ```

    Update its `EDITOR_SYSTEM_MANIFEST` too: `dependencies: ["HealthComponent"]`.

  </Step>

  <Step title="Add them to the game">

    In `src/main.ts`, give an entity the component and add the system:

    ```ts src/main.ts
    const player = registry.spawnEntity();
    registry.addComponent(player, new HealthComponent("player", 100));
    registry.addSystem(regenSystem);
    ```

    With `nf dev` running, the game rebuilds when you save.

  </Step>
</Steps>

See [`nf create`](/docs/cli/commands/create) for every option, and the
[component](/docs/cli/schematics/component) and [system](/docs/cli/schematics/system) pages for
the generated files.

## Install shared ones

Install packages of components and systems that others published on the registry:

```bash
nf install @my-org/health-bar
nf install @my-org/gravity@^2.0.0
```

Add an npm library to the project:

```bash
nf add --lib lodash-es
```

`nf install` writes each package, and the packages it needs, read only to
`nf_modules/@scope/name`, records it in `nanoforge.packages.json` and its lock, and adds a
`tsconfig.json` path for it, so you import it as `@my-org/health-bar/<file>`. Commit the two
`nanoforge.packages*.json` files, not `nf_modules`: `nf install` with no name installs what the
lock lists. See [`nf install`](/docs/cli/commands/install).
