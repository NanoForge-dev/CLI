## What it does

`nf editor` starts the NanoForge editor, a visual tool to build scenes, entities, components and
systems. It runs on your machine and you use it in the browser. It prints its URL:

```text
🔗 Editor running! Open it in your browser: http://localhost:5173
```

- **With a `[path]`**, it opens that project: the URL is `http://localhost:<port>/load?path=...`,
  and the browser opens by default once the editor answers (it waits up to 30 seconds).
- **Without a path**, the editor shows its project list, and no browser opens unless you pass
  `--open`.

The editor can open projects only inside its root folder. The root is the `-d` folder, or the
parent folder of `[path]` when the project is outside of `-d`.

What you can do in the editor is described in the [editor documentation](/docs/editor/getting-started/introduction).

## Usage

```bash
nf editor [path] [options]
```

## Options

| Option                        | Type    | Default                                 | Description                              |
| ----------------------------- | ------- | --------------------------------------- | ---------------------------------------- |
| `[path]`                      | path    | none                                    | Project to open, relative to `-d`.       |
| `-d, --directory <directory>` | path    | `.`                                     | Root folder of the editor.               |
| `-p, --port <port>`           | number  | `5173`                                  | Port of the editor, from 1 to 65535.     |
| `--open` / `--no-open`        | boolean | `true` with a `[path]`, `false` without | Open the editor in your default browser. |

## Environment variables

| Variable      | Description                                                                                                                         |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `DEV_PLUGINS` | Folder of a plugin you are building with [`nf create plugin`](./create). The editor loads it and reloads it when its build changes. |

## Examples

Open the project in the current folder:

```bash
nf editor .
```

Open a project on another port, without opening a browser tab:

```bash
nf editor ./my-game --port 5200 --no-open
```

Try a plugin you are building on a project:

```bash
DEV_PLUGINS=$PWD/score-board nf editor ./my-game
```

## Common errors

- **`Invalid editor port: <port>`.** The port must be a whole number from 1 to 65535.
- **The browser doesn't open.** The editor didn't answer within 30 seconds, or you ran it without
  a `[path]`. Open the printed URL yourself.
- **The port is already used.** Pass another `--port`.
