## What is the NanoForge CLI?

The NanoForge CLI (`nf`) is the tool you use to make games with
[NanoForge](https://github.com/NanoForge-dev), a game engine for the web browser.

One command covers each step of a game's life: create a project, add components and systems, run
it while you work, build it, serve it, open it in the editor, and share packages through the
NanoForge registry.

## What can it do?

<CardGroup cols={2}>
  <Card title="Create a project" href="../commands/new">
    Make a ready-to-run game: one client app, or a workspace with a client and a server.
  </Card>
  <Card title="Develop and run" href="../commands/dev">
    Run the game locally. Changes rebuild the game and reload the browser.
  </Card>
  <Card title="Add components and systems" href="../commands/create">
    Generate ECS components, systems, or an editor plugin.
  </Card>
  <Card title="Open the editor" href="../commands/editor">
    Start the NanoForge visual editor on your project.
  </Card>
  <Card title="Build and serve" href="../commands/build">
    Compile the client and server, then serve them with `nf start`.
  </Card>
  <Card title="Share packages" href="../commands/registry">
    Log in, publish, and install components and systems from the registry.
  </Card>
</CardGroup>
