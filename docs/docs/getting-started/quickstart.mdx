title: Quickstart

---

This page takes you from an empty folder to a game running in your browser.

<Steps>
  <Step title="Create a project">

    Run the project generator and answer its questions:

    ```bash
    nf new
    ```

    To skip the questions, give every answer as a flag:

    ```bash
    nf new --name my-game --package-manager npm --language ts --strict \
      --no-server --no-skip-install --no-docker --no-git
    ```

    `nf new` creates the project in `my-game/` and installs its dependencies.

  </Step>

  <Step title="Look at the project">

    ```bash
    cd my-game
    ```

    Without a server, the project is one client app:

    ```
    my-game/
    ├── nanoforge.config.ts   # what nf reads: type, entry file, folders
    ├── package.json
    ├── assets/               # copied next to the build
    └── src/
        ├── main.ts           # the game's entry point
        ├── components/
        └── systems/
    ```

    Each field of `nanoforge.config.ts` is described in the
    [configuration file reference](../configuration/configuration-file).

  </Step>

  <Step title="Run it while you work">

    ```bash
    nf dev
    ```

    Open [http://localhost:3000](http://localhost:3000). When you save a file in `src/`, `nf dev`
    rebuilds the game and the page reloads. Stop it with `Ctrl+C`.

  </Step>

  <Step title="Build and serve it">

    ```bash
    nf build
    nf start
    ```

    `nf build` writes the game to `dist/`. `nf start` serves that build on port 3000.

  </Step>
</Steps>

## Where to go next

- Add a server to your game: [create a project](/guides/cli/create-a-project) with `--server`.
- Add your own [components and systems](/guides/cli/components-and-systems).
- Read about every command in the [command reference](../commands/overview).
